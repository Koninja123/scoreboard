# Hockey Scoreboard

Mobiele scoreboard app voor gebruik als hockeyscheidsrechter op iPhone of Android.

## Functies
- Score bijhouden voor een blauw en rood team
- Teamnamen aanpassen en lokaal bewaren
- Aftelklok met 15 minuten, 30 minuten of vrije tijd
- Start, pauze en reset van de timer
- Alarm en duidelijke melding als de tijd verstreken is
- Werkt als lichte PWA en kan offline geladen worden na eerste bezoek

## Lokaal openen
Open `index.html` in een browser of start een simpele webserver in deze map.

Voorbeeld met Python:

```powershell
python -m http.server 8000
```

Ga daarna naar `http://localhost:8000`.

## Op mobiel gebruiken
- Open de app in Safari of Chrome op je telefoon
- Voeg de pagina toe aan het beginscherm
- De app opent daarna als een bijna-volledig scherm scoreboard
